# WorldClockProject
A responsive web application that displays the current time across multiple time zones worldwide. Built using HTML, CSS, and JavaScript, the project provides real-time clock updates and an intuitive user interface for tracking global time efficiently.

🚀 Features
Real-time clock updates
Multiple timezone support
Displays current date and time
Responsive design for desktop and mobile devices
Clean and intuitive user interface
Easy navigation between different locations

🛠️ Technologies Used
HTML5
CSS3
JavaScript
